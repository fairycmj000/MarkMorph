📖 MarkMorph 使用说明

最新更新（v1.0.15）

新功能

  • 多文件合并导出：多个 Markdown 合并为一个 HTML（顶部标签页 + 汇总目录 + 阅读进度条），顺序可拖拽调整、可重命名
  • 直接打开 .md 文件：双击 .md 文件直接用 MarkMorph 以 HTML 格式预览，并可下载保存为 .html
  • 预览实时同步：预览时监听源文件，外部编辑保存后自动刷新

功能增强

  • 首页四个入口改为 2×2 自适应布局，随窗口大小自动缩放
  • HTML 查看 导航栏优化：折叠 / 展开、拖动调整宽度、目录自动高亮跟随
  • 新增 仅内容区域缩放（50%–300%），左侧导航栏保持不变
  • 图片 / 流程图支持 单独放大查看（滚轮缩放、拖动平移）

BUG 修复

本版本无 BUG 修复。

一、快速上手

窗口内有四个入口，默认按 2×2 排列：

  • MD → PDF：先预览排版，再下载 PDF（自动生成书签目录）
  • MD → HTML：转换为网页并自动在浏览器中打开
  • MD → Word：转换为 .docx，可用 Word / WPS 继续编辑
  • 多文件合并：多个 .md 合并为一个 HTML

每个入口都支持两种选文件方式：把 .md 文件拖入对应区域，或点击该区域后在弹窗中选择文件。

二、直接打开 .md 文件

安装并完成文件关联后，双击 .md 文件（或右键 → 打开方式 → MarkMorph）：

  • 自动启动 MarkMorph，并直接以 HTML 格式预览该文件
  • 预览面板顶部按钮变为「下载 HTML」，点击即可保存为 .html
  • 若已运行，再次双击会把内容加载到当前窗口

三、多文件合并导出

把多个 Markdown 合并为一个 HTML 文档：

  • 把多个 .md 文件拖入「多文件合并」入口
  • 在合并列表中：拖拽整行调整顺序、点击文件名重命名、点击 ✕ 移除
  • 点击「生成合并 HTML」选择保存位置

生成的 HTML 顶部为标签页（切换文档）、侧边为汇总目录，并带顶部阅读进度条。

四、预览面板常用操作

目录导航栏

  • 左侧目录按标题层级自动生成，点击可平滑跳转
  • 滚动阅读时目录自动高亮当前章节并跟随
  • 点击目录顶部 « 收起，点击左侧边缘 » 展开
  • 拖动导航栏右缘可调整宽度（160–800px）

仅内容区域缩放

  • 点击预览面板顶部的 + / − 缩放正文，范围 50%–300%
  • 缩放只作用于正文内容区，左侧导航栏不变
  • 点击重置恢复 100%

图片单独放大查看

  • 点击正文中的图片（或流程图）可全屏放大查看
  • 支持鼠标滚轮缩放、按住拖动平移、底部 +/−/重置
  • 点击空白处、按 Esc 或右上角 × 关闭

五、更换背景

  • 左键点击右下角 🎨 按钮：选择自定义背景（jpg / png / webp / bmp / gif）
  • 右键点击 🎨 按钮：重置为默认背景

七、常见问题

流程图显示 "Syntax error"？

mermaid 节点标签中不支持 emoji（如 ⚠️ ✅ ❌），请替换为普通文字。

PDF 中文字体异常？

请确保系统已安装「微软雅黑」字体（Windows 默认已安装）。

应用打开后白屏？

等待 3–5 秒，应用首次启动需初始化；如持续白屏，关闭后重新打开。

图片转换后裂开 / 不显示？

请确认图片路径正确，建议把图片与 .md 放在同一目录或其子目录。

宽表格被压得看不清？

超过 4 列的表格会自动用 A3 横向输出；仍偏窄可精简列数或拆分表格。

如何恢复默认背景？

右键点击右下角 🎨 按钮即可重置。

右键 .md「打开方式」显示旧名称 Electron？

这是 Windows 缓存了旧的开发态记录。重装最新版后把 MarkMorph 设为默认；若旧条目残留，可在注册表 HKCU\...\FileExts\.md\OpenWithList 删除 electron.exe，或重启资源管理器。
