📖 MarkMorph 使用说明

最新更新

搜索与替换

  • 搜索定位：预览中按 Ctrl+F（或点 🔍）呼出搜索框，关键字逐条高亮定位
  • 替换：编辑态下支持「替换当前 / 全部替换」；多文件分屏每个分屏可独立搜索 + 替换，只读分屏点「替换」会自动切入编辑态再执行

编辑可撤销 / 重做

  • Ctrl+Z 撤销 / Ctrl+Y（或 Ctrl+Shift+Z）重做：手动输入、替换、插入图片均可撤销；连续输入自动合并为一步
  • 多文件分屏同样支持：每个分屏的编辑框都支持撤销 / 重做

Word 转换可直接编辑

  • Word → MD / HTML 可直接编辑转换结果：预览后点「编辑」修改转换结果再下载；编辑后的下载为自包含内容（图片内联，无需 assets 文件夹）

一、快速上手

窗口内有六个入口，默认按 2 列排列（共三行）：

  • MD → PDF：先预览排版，再下载 PDF（自动生成书签目录）
  • MD → HTML：转换为网页并自动在浏览器中打开
  • MD → Word：转换为 .docx，可用 Word / WPS 继续编辑
  • Word → MD：把 .docx 无损转换为 .md，图片提取到 assets/ 子文件夹，嵌入的 Excel 电子表格渲染为表格，预览确认后下载
  • Word → HTML：把 .docx 无损转换为 .html（图片内联、单文件自包含），预览确认后下载并在浏览器打开
  • 多文件：多个 .md 分屏并列预览，可编辑保存，并合并下载为 HTML / PDF / Word

每个入口都支持两种选文件方式：把文件拖入对应区域，或点击该区域后在弹窗中选择文件。

二、直接打开 .md 文件

安装并完成文件关联后，双击 .md 文件（或右键 → 打开方式 → MarkMorph）：

  • 自动启动 MarkMorph，并直接进入分屏预览（默认走「多文件」入口）
  • 可一次选中多个 .md 文件，同时分屏并列查看
  • 双击打开默认进入全屏预览（隐藏首页入口），点 ⛶ 退出全屏
  • 若已运行，再次双击会把内容加载到当前窗口

三、多文件（分屏预览 + 合并下载）

把多个 Markdown 一次性打开，分屏并列预览，并可合并下载为一个文档：

  • 把多个 .md 文件拖入「多文件」入口（最多 8 个），自动进入全屏分屏预览
  • 每个分屏都可编辑并保存 / 取消回源文件；拖动分屏标题调整顺序，点分屏右上角 ✕ 关闭
  • 点顶部布局切换按钮（▬/▦），在一行 8 格与上下两行各 4 格间切换，均等宽 / 等高铺满
  • 点右上角「合并下载」：勾选要合并的文件、拖动排序、双击文件名重命名，再选择格式（HTML / PDF / Word）
  • 预览中可点「+ 添加文件」继续追加 .md 文件（不超过 8 个）

合并为 HTML 时生成顶部标签页 + 汇总目录 + 阅读进度条；合并为 PDF / Word 时按指定顺序从上到下拼接内容。

四、预览面板常用操作

目录导航栏

  • 左侧目录按标题层级自动生成，点击可平滑跳转
  • 滚动阅读时目录自动高亮当前章节并跟随
  • 点击目录顶部 « 收起，点击左侧边缘 » 展开
  • 拖动导航栏右缘可调整宽度（160–800px）

仅内容区域缩放

  • 点击预览面板顶部「编辑」同行的 − / + 缩放正文，范围 50%–300%，中间显示当前比例
  • 缩放只作用于正文内容区，左侧导航栏不变
  • 点击重置恢复 100%

图片 / 流程图单独放大查看与下载

  • 点击正文中的图片（或流程图）可全屏放大查看
  • 支持鼠标滚轮缩放、按住拖动平移、底部 +/−/重置
  • 点底部「下载」按钮，可单独下载当前图片（原格式）或流程图（.svg）
  • 点击空白处、按 Esc 或右上角 × 关闭

编辑保存 / 取消 / 主题 / 全屏

  • 预览面板顶部 「编辑」：把当前预览切换为文本编辑框，可直接修改内容；编辑后点 「保存」 写回源 .md 文件，点 「取消」 放弃本次修改、不提交
  • 分屏预览时每个分屏可独立编辑保存 / 取消；拖动分屏标题调整顺序，点分屏右上角 ✕ 关闭该文件
  • 编辑时可插入图片：直接粘贴剪贴板图片，或点 「插入图片」（分屏为「插图」）从本地选择一张或多张图片，以 base64 内联写入，PDF / HTML / Word 均可显示
  • 若预览期间源文件被其他程序编辑保存，会弹出提示，当前窗口未保存的编辑不提交、自动回退只读
  • 🌙/☀️ 切换预览明亮 / 黑暗主题；⛶ 切换全屏（隐藏首页上传入口，退出后恢复）

五、更换背景

  • 左键点击右下角 🎨 按钮：选择自定义背景（jpg / png / webp / bmp / gif）
  • 右键点击 🎨 按钮：重置为默认背景

七、常见问题

流程图显示 "Syntax error"？

mermaid 节点标签中不支持 emoji（如 ⚠️ ✅ ❌），请替换为普通文字。

PDF 中文字体异常？

请确保系统已安装「微软雅黑」字体（Windows 默认已安装）。

应用打开后白屏？

等待 3–5 秒，应用首次启动需初始化；如持续白屏，关闭后重新打开。

图片转换后裂开 / 不显示？

请确认图片路径正确，建议把图片与 .md 放在同一目录或其子目录。

宽表格被压得看不清？

超过 4 列的表格会自动用 A3 横向输出；仍偏窄可精简列数或拆分表格。

如何恢复默认背景？

右键点击右下角 🎨 按钮即可重置。

右键 .md「打开方式」显示旧名称 Electron？

这是 Windows 缓存了旧的开发态记录。重装最新版后把 MarkMorph 设为默认；若旧条目残留，可在注册表 HKCU\...\FileExts\.md\OpenWithList 删除 electron.exe，或重启资源管理器。

每一行是一条记录，等价于 SQL 的 GROUP BY：你选的「层级」就是分组字段，从左到右逐级归并、长成一棵树。例：表有「大区 / 城市 / 门店」三列，层级依次选它们，就等于 GROUP BY 大区, 城市, 门店，得到 大区 → 城市 → 门店，节点旁的数字就是各组的行数。空单元格会保留成「（空）」节点，占住这一层的位置、不砍断后面的层级。
每一列是一个主体（列头 = 主体名），「标签列」指定某一列作为属性名，其余列作为属性值。例：列为「属性 / 旗舰店 / 社区店」，标签列选「属性」，即生成 旗舰店 → 面积 → 200㎡、社区店 → 面积 → 80㎡。「主体列」可拖拽调整顺序、增删。
每一行是一条「如果…那么…」规则，等价于 SQL 的 CASE WHEN … THEN …：条件列 = WHEN 里的判断，结果列 = THEN 后面的答案，节点统一写成「列名=具体值」。例：WHEN 面积=100㎡ AND 业态=社区 THEN 店型=社区店。空的条件单元格 = 不判断这个条件（跳过），但结果一定会显示。
