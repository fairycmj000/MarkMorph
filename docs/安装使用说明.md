# MarkMorph（格式转换工具）— 安装使用说明

版本：1.0.18 | 适用系统：Windows 10 / 11（64位）、macOS 10.13+

***

## 功能概览

一款把 Markdown（`.md`）文档一键转换为多种格式的桌面工具，支持：

- **MD → PDF**：先在右侧预览排版效果，确认后再下载 PDF，自动生成书签目录
- **MD → HTML**：转换为 HTML 网页并自动在浏览器中打开
- **MD → Word**：转换为 `.docx` 文档，可用 Word / WPS 打开继续编辑
- **Word → MD**：把 `.docx` 无损转换为 Markdown，图片提取到 `assets/` 子文件夹，嵌入的 Excel 电子表格渲染为表格
- **Word → HTML**：把 `.docx` 无损转换为 HTML 网页（图片内联、单文件自包含）
- **多文件分屏预览 + 合并下载**：把多个 Markdown 并列分屏预览、可编辑保存，合并下载支持 HTML / PDF / Word

六种转换均支持文档内的图片、表格、流程图，无需联网，开箱即用。

## 一、安装步骤

### Windows 系统

1. 双击安装包 `MarkMorph Setup 1.0.18.exe`
2. 选择安装目录（默认即可），点击"安装"
3. 安装完成后，桌面会自动出现 **MarkMorph** 快捷方式

> 安装过程中如弹出 Windows 安全提示，点击"仍要运行"即可。

> **升级安装提示**：如果之前装过旧版本，建议先卸载旧版再安装新版，避免图标或文件残留。

### macOS 系统

1. 双击下载的 `.dmg` 文件
2. 将 **MarkMorph** 图标拖拽到 **Applications** 文件夹
3. 在 Launchpad 或应用程序文件夹中找到并启动

> **首次打开提示**：如果提示"无法打开，因为无法验证开发者"，请按以下步骤操作：
> 1. 打开"系统偏好设置" → "安全性与隐私"
> 2. 在"通用"标签页底部，点击"仍要打开"
> 3. 再次确认"打开"即可正常使用

## 二、使用方法

### 启动应用

双击桌面 **MarkMorph** 图标，应用窗口自动打开。窗口内有六个上传入口，默认按 **2 列**排列（共三行），随窗口大小自动缩放、不会超出显示区域：

- **MD → PDF**
- **MD → HTML**
- **MD → Word**
- **Word → MD**
- **Word → HTML**
- **多文件**（分屏预览 + 合并下载 HTML / PDF / Word）

每个入口都支持两种选择文件的方式：

- **拖拽**：将 `.md` 文件直接拖入对应区域
- **点击选择**：点击对应区域，在弹出的文件框中选择 `.md` 文件

### 直接打开 .md 文件（分屏预览）

安装并完成文件关联后，**直接双击 `.md` 文件**（或右键 → 打开方式 → MarkMorph）：

- 自动启动 MarkMorph，并**直接进入分屏预览**（默认走「多文件」入口）
- 可**一次选中多个** `.md` 文件，同时分屏并列查看
- 双击打开默认进入**全屏预览**（隐藏首页入口），点 ⛶ 退出全屏
- 若已运行实例，再次双击文件会把内容加载到当前窗口

### 转换为 PDF（先预览后下载）

1. 把 `.md` 文件拖入或点选到 **MD → PDF** 入口
2. 右侧自动弹出 **预览面板**，可查看真实排版效果（含图片、表格、流程图）
3. 确认无误后，点击预览面板顶部的 **"下载 PDF"** 按钮
4. 选择保存位置，即可生成 PDF

> PDF 会根据标题层级自动生成书签目录，方便在阅读器中跳转。

### 转换为 HTML

1. 把 `.md` 文件拖入或点选到 **MD → HTML** 入口
2. 选择保存位置
3. HTML 文件生成后会自动在默认浏览器中打开

### 转换为 Word

1. 把 `.md` 文件拖入或点选到 **MD → Word** 入口
2. 选择保存位置
3. 生成 `.docx` 文件并自动打开，可直接用 Word 或 WPS 编辑

> Word 转换会完整保留表格（含单元格内的图片）、标题层级、加粗/斜体、换行等格式，表格内文字自动左对齐。

### 转换为 Markdown（Word → MD）

把 Word 文档（`.docx`）无损转换为 Markdown（`.md`）：

1. 把 `.docx` 文件拖入或点选到 **Word → MD** 入口
2. 右侧自动弹出**预览面板**，核对转换结果（标题层级、表格、图片、嵌入表格、超链接等）
3. 确认无误后，点击预览面板顶部的 **"下载 MD"** 按钮
4. 选择保存位置，生成 `.md` 文件，同目录下会自动生成 `assets/` 子文件夹存放图片

> **无损转换范围**：标题层级（H1–H6）、段落、编号 / 项目列表、加粗 / 斜体、Word 原生表格（含合并单元格、嵌套表格）、图片、超链接都会完整写入 md；嵌入的 **Excel 电子表格**会渲染成 Markdown 表格（不保留 `.xlsx` 原文件）。图片按相对路径 `./assets/图片名` 引用，移动 md 时请连同 `assets/` 一起移动。

### 转换为 HTML（Word → HTML）

把 Word 文档（`.docx`）无损转换为 HTML 网页：

1. 把 `.docx` 文件拖入或点选到 **Word → HTML** 入口
2. 右侧自动弹出**预览面板**，核对转换结果（标题层级、表格、图片、嵌入表格、超链接等）
3. 确认无误后，点击预览面板顶部的 **"下载 HTML"** 按钮
4. 选择保存位置，生成**单文件自包含**的 `.html` 文件并自动在浏览器中打开

> 图片会以 base64 内联进 HTML，移动或分享该 `.html` 无需附带其他文件；转换范围与 Word → MD 一致（标题、表格、嵌套表格、图片、超链接、嵌入的 Excel 渲染为表格）。多行表格会在表头处自动生成**字段筛选下拉框**，方便快速过滤表格内容。

### 多文件（分屏预览 + 合并下载）

把多个 Markdown 文件一次性打开，**分屏并列预览**，并可**合并下载**为一个文档：

1. 把多个 `.md` 文件拖入（或点选加入）**多文件**入口（最多 8 个），自动进入**全屏分屏预览**
2. 分屏预览中：
   - 每个分屏显示一个文件，可**编辑并保存 / 取消**回源文件
   - **拖动分屏标题**调整顺序，点分屏右上角 ✕ 关闭该文件
   - 点「+ 添加文件」继续追加 `.md` 文件（不超过 8 个）
   - 点预览面板顶部「布局」按钮，在**一行 8 格**与**上下两行各 4 格**之间切换，均等宽 / 等高铺满
3. 点预览面板右上角「合并下载」，在弹出的窗口中：
   - **勾选**要合并的文件
   - **拖动排序**（排在前面的先合并）
   - **双击文件名重命名**
   - 选择合并格式：**HTML / PDF / Word**
4. 合并为 **HTML**：生成顶部标签页 + 汇总目录 + 阅读进度条（与单文件 HTML 一致）
5. 合并为 **PDF / Word**：按指定顺序把各文件内容**从上到下**拼接为一个文档

> 下载后的 HTML 为**只读**：标签页仅用于切换文档，不可重命名或拖拽排序。如需调整文件顺序或名称，请在下载前于合并弹窗中完成，下载时会按最新名称与顺序生成。

### 预览面板（HTML 查看）常用操作

生成的 HTML 预览（含 PDF 预览、HTML 导出、合并导出）带左侧**目录导航栏**，并支持内容缩放与图片放大查看：

**导航栏**

- 左侧**目录**按标题层级自动生成，点击可平滑跳转
- 滚动阅读时，目录自动**高亮当前章节**并跟随滚动
- 点击目录顶部的 **«** 可**收起**导航栏，点击左侧边缘的 **»** 展开
- 拖动导航栏右侧边缘可**调整宽度**（160–800px）

**仅内容区域放大 / 缩小**

- 点击预览面板顶部 **「编辑」同行的 − / +** 按钮缩放正文，范围 50%–300%，步进 10%，中间显示当前缩放比例
- 缩放**只作用于正文内容区**，左侧目录导航栏保持不变
- 点击**"重置"**恢复 100%

**图片 / 流程图单独放大查看与下载**

- **点击**正文中的任意图片，可**全屏放大查看**
- 放大后支持：鼠标**滚轮**缩放（以光标为中心）、按住**拖动平移**、底部 **+ / − / 重置** 按钮
- 点击空白处、按 **Esc** 或右上角 **×** 关闭
- 流程图（mermaid）同样支持点击放大查看
- 放大查看时点底部 **「下载」** 按钮，可**单独下载**当前图片或流程图（图片按原格式保存、流程图为 `.svg`）

**编辑保存 / 取消 / 主题 / 全屏**

- 预览面板顶部 **「编辑」**：把当前预览切换为文本编辑框，可直接修改内容；编辑后点 **「保存」** 写回源 `.md` 文件，点 **「取消」** 放弃本次修改、不提交
- 分屏预览时每个分屏可**独立编辑保存 / 取消**；拖动分屏标题调整顺序，点分屏右上角 ✕ 关闭该文件
- 编辑时可**插入图片**：直接**粘贴**剪贴板图片，或点 **「插入图片」**（分屏为「插图」）从本地选择**一张或多张**图片，以 base64 内联写入，PDF / HTML / Word 均可显示
- **🌙/☀️** 切换预览**明亮 / 黑暗主题**；**⛶** 切换**全屏**（隐藏首页上传入口，退出后恢复）
- 若预览期间源文件被**其他程序**编辑保存，会弹出提示，当前窗口未保存的编辑**不提交**、自动回退只读

**更换背景**：见下方"更换 / 重置背景图片"

### 预览实时同步

在**预览面板打开期间**，工具会监听源 `.md` 文件。若你用**其他编辑器修改并保存**同一份文档，预览会自动刷新为最新内容，无需重新打开：

- 适用于 PDF 预览、HTML 预览、双击 `.md` 打开预览，以及多文件分屏预览
- 保存后约 0.3 秒内自动刷新，状态栏会提示「已自动同步外部修改」
- 自动同步后点击「下载」导出的也是最新内容；关闭预览面板即停止监听
- **编辑冲突保护**：若你正在应用内编辑该文件，而源文件被其他程序修改保存，会弹出提示「有其他程序编辑了文档内容，在当前窗口的编辑不生效」，当前窗口未保存的编辑**不会被提交**，并自动回退为只读状态

### 大表格自动适配纸张

当文档中存在**超过 4 列**的表格时，PDF 和 HTML 会**自动切换为 A3 横向纸张**输出，避免宽表格被压缩或截断；普通文档仍按 A4 输出。

### 图片自适应

文档中的图片会按**行**自动排版：

- **单张图片占一行**：自动适配页面宽度（只缩不放，小图保持原大小，不会撑破排版）
- **多张图片连续排列**：自动并排，**每行最多 3 张**，行内图片均分页面宽度；超过 3 张自动换行
- 本地相对路径的图片也能正确加载（会以内嵌方式打包进结果文件）

### 更换 / 重置背景图片

- **左键点击** 窗口右下角的 🎨 按钮：选择自定义背景图片（支持 jpg、png、webp、bmp、gif 格式）
- **右键点击** 🎨 按钮：重置为默认背景图片（会清除已保存的自定义背景）

### 版本水印

应用内会显示**当前版本号与构建日期**水印，便于确认正在使用哪个版本。

### 查看使用说明

- **点击** 窗口右下角的「使用说明」按钮（竖排标签，位于 ↕ 与 🎨 上方）：弹出完整使用说明，含最新更新与各功能详细操作
- 弹窗支持点击遮罩、右上角 × 或按 Esc 关闭

## 四、常见问题

**Q：流程图显示为"Syntax error"？**
A：mermaid 流程图节点标签中不支持 emoji（如 ⚠️ ✅ ❌）。请将节点文字中的 emoji 替换为普通文字后重新转换。

**Q：PDF 中文字体显示异常？**
A：确保系统已安装"微软雅黑"字体（Windows 系统默认已安装）。

**Q：应用打开后白屏？**
A：等待 3-5 秒，应用首次启动需要初始化。如持续白屏，尝试关闭重新打开。

**Q：PDF / HTML / Word 文件保存在哪里？**
A：转换时会弹出保存对话框，由您自行选择保存位置。

**Q：文档里的图片转换后裂开 / 不显示？**
A：请确认图片路径正确。本地图片建议与 `.md` 文件放在同一目录或其子目录下，工具会自动读取并内嵌。（1.0.3 及以上已修复本地图片加载问题）

**Q：宽表格在 PDF 里被压得看不清？**
A：超过 4 列的表格会自动用 A3 横向输出。如果仍偏窄，可适当精简列数或拆分表格。

**Q：转 Word 后标题里出现多余的 `\` 符号（如 `3\.2`）？**
A：这是旧版本的转义处理问题，1.0.5 已修复。请使用 1.0.5 及以上版本重新转换。

**Q：转 Word 后换行显示为 `<br>` 文字、表格内容混乱？**
A：1.0.3 及以上已修复换行和表格转义问题，请使用最新版本。

**Q：如何恢复默认背景？**
A：**右键点击**窗口右下角的 🎨 按钮，确认后即可重置为默认背景。（无需手动删除文件）

**Q：更换背景后，卸载重装仍显示自定义背景？**
A：自定义背景保存在用户数据目录中，卸载时不会自动删除。**右键点击** 🎨 按钮重置背景即可；或手动删除下方"卸载方法"中提到的用户数据目录。

**Q：安装后应用图标不是小王子图标？**
A：这是 Windows 图标缓存问题。请运行随附的 `清理图标缓存.bat`（右键以管理员身份运行），或参考下方"图标显示问题"章节手动清理。升级到新版本号并重装通常也能强制刷新图标。

**Q：右键 `.md` 文件的"打开方式"里显示旧名称 Electron？**
A：这是 Windows 缓存了旧的开发态记录。重新安装最新版后，可在"打开方式"列表里把 MarkMorph 设为默认；若旧条目仍残留，可在注册表 `HKCU\...\Explorer\FileExts\.md\OpenWithList` 中删除 `electron.exe` 条目，或重启资源管理器。

## 五、卸载方法

### Windows 系统

可任选以下任一方式卸载：

**方式一：通过设置（推荐）**
1. 打开 **设置 → 应用 → 应用和功能**（或"已安装的应用"）
2. 搜索"MarkMorph"
3. 点击右侧的"···"或直接点击应用，选择"卸载"
4. 按提示完成卸载

**方式二：通过控制面板**
1. 打开 **控制面板 → 程序 → 程序和功能**
2. 在列表中找到"MarkMorph"
3. 右键选择"卸载"，按提示完成

**方式三：通过开始菜单**
1. 打开开始菜单，找到"MarkMorph"文件夹
2. 点击"卸载 MarkMorph"，按提示完成

### macOS 系统

1. 打开 **Finder**，进入"应用程序"文件夹
2. 找到 **MarkMorph**，右键选择"移到废纸篓"
3. 清空废纸篓完成卸载

### 彻底清理用户数据（可选）

卸载程序**不会**删除用户配置和自定义背景图片。如需彻底清理，请手动删除以下目录：

- **Windows**：`C:\Users\<你的用户名>\AppData\Roaming\MarkMorph\`
  （在文件资源管理器地址栏输入 `%AppData%\MarkMorph` 可直接打开）
- **macOS**：`~/Library/Application Support/MarkMorph/`

> 该目录保存了自定义背景图片和配置文件。删除后下次安装将恢复为默认设置。

## 六、图标显示问题

如果安装后应用图标显示不正确（不是小王子图标），是 Windows 图标缓存导致的，按以下方法清理：

### 自动清理（推荐）

右键以管理员身份运行随附的 `清理图标缓存.bat`，等待完成后检查图标。

### 手动清理

1. 按 `Ctrl + Shift + Esc` 打开任务管理器
2. 找到"Windows 资源管理器"进程，右键选择"结束任务"
3. 按 `Win + R`，输入以下命令并回车：
   ```
   del /a /q %localappdata%\IconCache.db
   ```
4. 在任务管理器中点击"文件 → 运行新任务"，输入 `explorer.exe` 回车
5. 如仍未生效，重启电脑
